Text Changer Application
=====================

Project Structure:
- MainWindow.xaml: Interface użytkownika
- MainWindow.xaml.cs: Logika aplikacji
- Lorem.txt: Przykładowy plik wejściowy
- Output.txt: Plik wyjściowy (generowany po zapisie)

Funkcjonalność:
1. Otwieranie pliku Lorem.txt
2. Wyszukiwanie i zamiana tekstu
3. Zapisywanie zmienionego tekstu do pliku Output.txt

Wymagania systemowe:
- Windows
- .NET Framework
